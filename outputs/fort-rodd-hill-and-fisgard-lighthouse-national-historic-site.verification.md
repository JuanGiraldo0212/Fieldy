# VERIFICATION — Fort Rodd Hill and Fisgard Lighthouse National Historic Sites

- **Fields checked:** 96 non-null fields — venue block (28, including four `facility_notes` entries), four programs (about 33), five images (30) — each re-read against the page recorded in `source_url` / `found_on_url`.
- **Fields corrected:** 2
  - `programs[1].indoor` (Fit to Serve): true -> null. The site describes team challenges around the fort but never says the program goes inside; `outdoor: true` is supported by "Our programs run rain or shine" and the instruction to dress for the weather.
  - `programs[2].indoor` (WWI Medical): true -> null, same reason — the page never states where the casualty clearing station scenario is staged.
- **Fields set to null / left null after review:**
  - All four programs' cost fields except the self-guided visit. The booking page says "To book a school program and fee information, call" — the fee is genuinely unpublished, and the fees page's "Heritage Presentation Special Programs" table (guided tours by duration and group size) was **not** borrowed for the school programs, because nothing on the site says those rates are what a school pays.
  - `hosts_daycare_groups`: null. School programs start at kindergarten and the site is silent about under-fives, which the schema treats as null rather than false.
  - `stroller_accessible`: null. The accessibility page cuts both ways — a curb cut "wide enough to accommodate most mobility aids and strollers", but a cement block that stops a large stroller circling the lighthouse and beach paths with roots and soft sand. Recorded as a gap instead of a Yes/No tile.
  - `chaperone_ratio`: null on all programs. The "maximum six per group" line refers to challenge teams for the Platoon Challenge tour, not to adult supervision.
- **Conflicts recorded:** 1 — the teacher information page (2025-08-05) lists a washroom outside the front kiosk, while the accessibility page (2026-08-18) says that washroom is temporarily closed for renovation. Both statements are kept in `facility_notes.washrooms`; `has_washrooms` stays true because the lighthouse and Second World War Officer's Quarters washrooms are open.
- **Price re-check (cache-busted):** the fees page was fetched with a `?v=1` cache-buster, so the admission figures ($10 adult, $8.50 senior, $8.50 commercial group per person, youth free) come from a fresh response. The page is dated 2025-12-03 and states "Regular fees apply as of September 8, 2026", which is recorded in `price_year_or_season` and `seasonal_notes` — today is 2026-09-03, so the free Canada Strong Pass admission window still has four days to run.
- **Grade check:** all three school programs publish grades, never ages, so `age_basis` is `grades` and both age fields are null: K-6 -> 0 to 6, 7-12, 9-12. No grade was converted to an age.
- **Duration:** 90 minutes on all three school programs comes from the teacher information page ("there are no breaks during the 1.5 hour program"), which is written for school field trips generally. Per-program durations are not published individually — recorded as a gap.
- **`has_rain_backup: false`** is a deliberate reading, not an omission: the site says "Our programs run rain or shine" and tells teachers to dress students for the weather, and the teacher page says there are no indoor eating areas. There are indoor shelters on site (Casemates Barracks, Fortress Plotting Room, Canteen) but nothing that says a booked program moves indoors.
- **Self-guided visit program — note for the reviewer:** `age_max_years: 17` with `is_free: true` is the site's own pairing ("Free admission for youth 17 and under"), not an age limit on who may visit. It is the fee boundary, and adults are recorded separately at $10. This is the program that lets the record clear the publishable bar, since the three school programs have grades but no published price.
- **Authored fields written:**
  - `what_children_do` for all four, grounded in the site's "During this program students will" lists (explore the lighthouse, practise Morse code and hand signals, play a nurse or a wounded soldier) and, for the self-guided visit, the accessibility page's description of the causeway, lighthouse stairs, meadow trail and beaches.
  - `our_note` for all four, resting on the unpublished fee, the ninety minutes with no breaks, the coastal wind, and the fact that nothing is sold on site.
  - `practical_summary` for all four, built from the facility fields (washrooms yes, picnic areas but no indoor eating, rain or shine) plus the gaps list.

- **Images:** 5 entries, all on `pcweb2.azureedge.net`, which is Parks Canada's own media CDN, all https, all confirmed present on the page recorded in `found_on_url`. - **Confidence:** high. This is the best-documented of the three venues — grades, season, duration, washrooms, lunch arrangements, languages and detailed accessibility are all published on the site's own pages, and the only significant hole is the school program fee, which the site deliberately routes to a phone call.
